# Проверка принадлежности интервалу

В `interval.py` функция `contains(value, start, end)` должна проверять принадлежность целого числа полуоткрытому интервалу `[start, end)`: левая граница включается, правая исключается.

При `start == end` интервал пуст. При `start > end` функция должна по-прежнему поднимать `ValueError`. Для допустимых границ результат — `bool`. Все три аргумента — целые числа; обработка других типов в задачу не входит.

Сохраните имя функции, имена и порядок аргументов. Файл `legacy.py` используется существующими клиентами для закрытых интервалов и должен остаться без изменений.

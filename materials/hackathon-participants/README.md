# Хакатон: генератор тест-кейсов с LLM

Создайте программу, которая получает репозиторий и описание задачи, использует LLM и автоматически выпускает тест-кейс в заданном формате. Такую программу далее называем **харнессом**.

**Тест-кейс** — самостоятельная задача для AI-разработчика: исходный код, задание, окружение для запуска, скрытые проверки и эталонное решение. Он нужен, чтобы измерить, справляется ли AI с изменением кода: проверки должны отклонять исходное поведение и принимать корректное решение.

## Материалы

- [PROTOCOL.md](PROTOCOL.md) — входные параметры, формат результата и требования к приёмке.
- [example-case/](example-case/) — небольшой работающий пример **полной папки кейса**, включая Dockerfile, тесты и решение. В [README примера](example-case/README.md) описаны файлы и команды запуска.
- [meridian/](meridian/) — банковский проект на Python и PostgreSQL, на котором будет работать ваш генератор.

## Что сдавать

1. Исходники вашего харнесса и инструкцию его запуска с входными параметрами.
2. Результаты проверок и сведения об использовании LLM в формате протокола.

Язык реализации, инструменты, интерфейс и архитектура — на ваше усмотрение. Оценивается автоматическая генерация кейсов и качество полученного результата. Исходный проект при запуске должен оставаться неизменным.
